La plupart des chaudières modernes affichent un code quand elles se mettent en sécurité, une combinaison de lettres et de chiffres, parfois un simple voyant qui clignote selon un rythme précis. Ce code n'est pas réservé au technicien, bien lu et bien transmis, il accélère considérablement le diagnostic au téléphone, parfois au point d'éviter un déplacement pour un défaut qui se résout à distance.

## Où trouver le code et comment le noter

Le code s'affiche en général sur le petit écran de la chaudière, parfois accompagné d'un symbole ou d'une icône. Sur les appareils plus anciens sans écran, c'est un voyant qui clignote selon une séquence précise, qu'il faut alors compter et noter, par exemple trois clignotements suivis d'une pause. Dans les deux cas, une photo de l'écran ou une note écrite du nombre de clignotements est bien plus fiable qu'un souvenir approximatif transmis quelques minutes plus tard au téléphone.

## La marque et le modèle comptent autant que le code

Chaque fabricant a son propre système de codes, et parfois même chaque gamme au sein d'une même marque. Le même code peut signifier des choses différentes d'un fabricant à l'autre. L'étiquette signalétique, collée sur le flanc ou à l'intérieur de la trappe de la chaudière, indique la marque et la référence exacte du modèle, deux informations qui permettent d'interpréter correctement le code affiché.

## Ce qu'un bon appel contient

1. **Le code exact**, tel qu'il s'affiche, chiffres et lettres compris, ou le nombre de clignotements comptés précisément.
2. **La marque et le modèle**, relevés sur l'étiquette de l'appareil.
3. **Le moment d'apparition**, au démarrage, en cours de fonctionnement, après une coupure de courant.
4. **Ce qui a déjà été tenté**, un réarmement par exemple, et ce qui s'est passé ensuite.

Avec ces quatre éléments, un chauffagiste identifie souvent la famille de panne au téléphone, sait dire si l'intervention peut attendre un créneau programmé ou si elle est urgente, et arrive avec la pièce probablement en cause plutôt qu'en simple exploration.

## Le cas du code qui disparaît après réarmement

Un code qui s'efface après un réarmement ne signifie pas que le problème est résolu. Le réarmement remet l'appareil en route, il ne corrige pas la cause du défaut. Si le code est réapparu une ou plusieurs fois, même effacé au moment de l'appel, le signaler reste une information précieuse, c'est souvent ce qui distingue un incident isolé d'une panne qui s'installe.
